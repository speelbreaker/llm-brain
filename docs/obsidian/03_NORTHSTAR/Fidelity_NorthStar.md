# Fidelity NorthStar

## Immutable vision
- Deliver confidence in every signal before it issues from the trading stack.
- Keep risk, compliance, and position symmetry aligned so the bot never surprises the desk.
- Treat the live deribit feed as sacred; the NorthStar is accuracy, not speed alone.

## Principles
1. Validate any automation change against historical fidelity metrics before release.
2. Preserve permission gates (`can_trade`, `close_only_mode`) in every live path.
3. Keep telemetry and health indicators in place so deviation from the NorthStar raises alerts.
