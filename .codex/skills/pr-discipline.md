# Skill: PR Discipline

## Context
PRs are the unit of work. The Supervisor loop manages them.

## Rules
1.  **One PR = One Queue Item**: Do not mix tasks.
2.  **Clean History**: Squash commits before merge.
3.  **Supervisor Driven**:
    -   Let the Supervisor run verification.
    -   Address feedback via new commits or debate.
    -   Wait for "Ready to Merge" signal.
4.  **No Force Push**: Unless fixing a messed-up rebase on a feature branch.
